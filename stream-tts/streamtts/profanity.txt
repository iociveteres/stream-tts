# Корни мата для фильтра. Слово с таким корнем вырезается, на его месте звучит писк.
# Сравнение идёт после нормализации: регистр, ё -> е, латиница-двойники (xуй, пuзда) и цифры (6ля)
# заменяются кириллицей, разделители внутри слова (х.у.й, х-у-й) и повторы букв (хууууй) убираются.
#
#   корень     корень в любом месте слова (пизд: спиздил, распиздяй)
#   ^корень    корень в начале слова, можно после приставки (^еб: ебать, заебал, отъебись)
#   !начало    исключение: слово (или слово без приставки) с таким началом не трогается
#   +приставка дополнительная приставка для ^корней
#
# Строки с # — комментарии. Файл перечитывается при сохранении из интерфейса или при перезапуске.
