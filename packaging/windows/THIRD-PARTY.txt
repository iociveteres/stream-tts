StreamTTS для Windows включает сторонние программы. Их лицензии:

cosyvoice.cpp v0.2.0 (cosyvoice-server, cosyvoice-cli, cosyvoice.dll) — MIT
  https://github.com/Lourdle/cosyvoice.cpp
GGML из llama.cpp b11500 (ggml*.dll) — MIT
  https://github.com/ggml-org/llama.cpp
LLVM OpenMP (libomp.dll) — Apache-2.0 with LLVM exception,
  см. LICENSE-LLVM-OpenMP
ONNX Runtime (onnxruntime*.dll) — MIT
  https://github.com/microsoft/onnxruntime
ICU 78.3 (icu*.dll) — Unicode License v3, см. icu-LICENSE
  https://github.com/unicode-org/icu
FFmpeg 8.1 (av*.dll, sw*.dll, ffmpeg.exe), сборка BtbN lgpl-shared —
  LGPL 2.1 or later, см. ffmpeg-LICENSE.txt
  Исходный код: https://github.com/FFmpeg/FFmpeg (ветка release/8.1)
  Сборка: https://github.com/BtbN/FFmpeg-Builds
NVIDIA CUDA Runtime и cuBLAS (cudart64_13.dll, cublas64_13.dll,
  cublasLt64_13.dll; компонент CUDA) — NVIDIA CUDA Toolkit EULA,
  распространяемые файлы: https://docs.nvidia.com/cuda/eula/
Microsoft Visual C++ Redistributable (vcruntime140*.dll, vc_redist.x64.exe) —
  лицензия Microsoft на распространяемый код Visual Studio
Python 3.14 (python314.dll, *.pyd) — PSF License 2.0
  https://docs.python.org/3/license.html
  В его составе: OpenSSL (libssl-3.dll, libcrypto-3.dll) — Apache-2.0,
  libffi — MIT, SQLite — public domain
Пакеты Python: aiohttp — Apache-2.0 и MIT; aiosignal, frozenlist, multidict,
  propcache, yarl — Apache-2.0; aiohappyeyeballs — PSF-2.0; attrs — MIT;
  idna — BSD-3-Clause; numpy (с OpenBLAS в numpy.libs) — BSD-3-Clause
Nuitka (компилятор программы): его runtime в StreamTTS.exe — AGPLv3
  с Nuitka Runtime Library Exception, которое разрешает распространять
  собранную программу под любой лицензией
