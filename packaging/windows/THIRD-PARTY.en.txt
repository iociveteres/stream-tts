The speech model (CosyVoice3 0.5B, Apache-2.0) is not part of the installer:
the program downloads it on the Server tab from
https://huggingface.co/Lourdle/Fun-CosyVoice3-0.5B-2512-GGUF

The music removal model (Demucs v4 htdemucs in ONNX) is not part of the
installer: it is downloaded on request in the settings from
https://huggingface.co/HRSadeghi/demucs-onnx
The Demucs and export code is MIT, but the weights were trained on MusDB
and, according to the Demucs author, are for research use only
(https://github.com/facebookresearch/demucs/issues/327).

Note: the StreamTTS interface is in Russian.
