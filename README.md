# StreamTTS

Озвучка наград и чата Twitch локальным синтезом речи. Зритель тратит баллы канала или пишет `!tts текст` — фраза
звучит на стриме выбранным голосом. Синтез идёт на вашем компьютере, без облачных сервисов.

## Возможности

- Три модели синтеза, переключаемые в админке:
  - [ESpeech](docs/espeech.md) (F5-TTS) — естественное звучание, простановка ударений, желательно дообучение LoRA для добавления новых голосов;
  - [CosyVoice3](https://huggingface.co/Lourdle/Fun-CosyVoice3-0.5B-2512-GGUF) — простое добавление новых голосов;
  - [Supertonic 3](docs/supertonic.md) — лёгкая модель, способная работать на процессоре, имеет 10 готовых голосов.
- TTS как награда за баллы, команда в чате или озвучка всех сообщений; настройка кулдаунов, уровней доступа, фильтр мата.
- Выбор голоса зрителем, динамически генерируемая страница с доступными голосами.
  Страницу можно опубликовать на GitHub Pages с постоянным адресом — кнопкой в админке, нужен аккаунт GitHub.
- Админка в браузере со всеми настройками.

## Установка

### Windows

1. Скачайте `StreamTTS-Setup-<версия>.exe` со страницы [Releases](https://github.com/iociveteres/stream-tts/releases).
2. Запустите. Права администратора не нужны, всё хранится в папке программы. Админка откроется сама.

### Docker

Linux или Windows 10/11 с Docker Desktop (WSL2), Docker Compose v2, процессор x86_64 с AVX2.

1. В пустой папке скачайте compose-файл (в PowerShell — `curl.exe`):

   ```bash
   curl -fsSLO https://raw.githubusercontent.com/iociveteres/stream-tts/main/docker-compose.yml
   ```

2. Запустите — папки настроек, моделей и голосов появятся рядом:

   ```bash
   docker compose up -d
   ```

3. Откройте **http://localhost:8090**.

С видеокартой NVIDIA скачайте ещё один файл и запускайте с обоими:

```bash
curl -fsSLO https://raw.githubusercontent.com/iociveteres/stream-tts/main/docker-compose.gpu.yml
```

```bash
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d
```

Обновление:

```bash
docker compose pull
```

```bash
docker compose up -d
```

## Первый запуск

1. **Загрузки** — скачайте модель, для видеокарт NVIDIA — ещё и CUDA.
2. **Twitch** — по гайду подключите приложение на dev.twitch.tv (Client Type: **Public**). Там же
   выберите, как зрители заказывают озвучку: награда, команда, все сообщения. Или при отсутствии 2FA используйте режим «Только чтение чата», который не поддерживает награды.
3. **Голоса** — «+ Добавить голос» из своей записи (5–15 с чистой речи и точный текст) или готовый zip в «Наборах
   голосов» из стороннего источника.
4. **Очередь** — добавьте оверлей в OBS: Источник → Браузер. OBS на этом компьютере — `http://localhost:8090/overlay`,
   на другом — `http://<адрес компьютера>:8090/overlay` (см. «Доступ по сети»). Проверьте тестовой активацией.
5. **Док-панель** (по желанию) — пауза, громкость и очередь прямо в окне OBS: Док-панели → Пользовательские
   док-панели браузера, адрес `http://localhost:8090/dock`.

## Команды чата

| Команда | Что делает |
|---|---|
| `!tts <текст>` | озвучить текст (имя команды меняется в админке) |
| `!ttssf <голос>` | выбрать свой голос |
| `!ttsvoices` | ссылка на страницу голосов |
| `!ttsskip`, `!ttsclear` | модеры и стример: прервать фразу, очистить очередь (баллы возвращаются) |
| `!ttsban <ник>`, `!ttsunban <ник>` | модеры и стример: запретить или разрешить зрителю озвучку |
| `!ttson`, `!ttsoff` | модеры и стример: включить или выключить озвучку |

## Требования

| | |
|---|---|
| Процессор | x86_64 с AVX2 (Intel 4-го поколения и новее, AMD Zen); macOS и ARM не поддерживаются |
| ОЗУ | ~4 ГБ свободной для CosyVoice3 Q8_0, ~1,5 ГБ для ESpeech, ~0,5 ГБ для Supertonic 3 |
| Диск | ~2 ГБ с моделью CosyVoice3; CUDA — ещё ~730 МБ, ESpeech — ~2,3 ГБ загрузки |
| Видеокарта (необязательно) | NVIDIA с драйвером R580+; видеопамяти 1,5–2 ГБ для CosyVoice3, ~0,9 ГБ для ESpeech, 1,3–3,5 ГБ для обучения LoRA |

## Доступ по сети

- Docker открыт в локальную сеть сразу. Закрыть — строка `STREAM_TTS_BIND=127.0.0.1` в `.env` рядом с
  compose-файлом.
- Программа для Windows по умолчанию доступна только с этого компьютера. Открыть в сеть — строка
  `STREAM_TTS_BIND=0.0.0.0` в `data\stream-tts.env` в папке программы, затем перезапуск.
- Из локальной сети админка и оверлей открыты без пароля: `http://<адрес компьютера>:8090`.
- Из интернета — только с паролем: «Настройки» → «Сервер». Забыли пароль — удалите файл `admin-password` из папки
  данных и перезапустите.
