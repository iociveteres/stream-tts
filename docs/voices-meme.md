# Мемные голоса для стрима (как в JeetBot TTS)

Скрипты лежат в `tools/meme/` (эффекты поверх синтеза — в `effects/`) и запускаются из корня проекта. Часть кода общая с подбором голосов WC3 ([voices-wc3.md](voices-wc3.md)): `meme-pick.py` берёт сервер отслушивания из `tools/wc3/review.py`, `score-speaker.py` — эмбеддинги CAM++ из `tools/wc3/synth-ab.py`.

Образцы лежат в `voice-refs/meme/` (`manifest.json` хранит исходные файлы и текст), голоса — в `voices/`.

|---|---|---|

| `***` | *** | клип «что тяжелее, кг ваты или кг гвоздей» (***, 0:32–0:54; вариант P01) |
| `***` | ***, стример, для которого эти голоса | закадровый голос из его видео *** Awards 2025 (***, 0:53–1:12), голос отделён от подложки demucs (вариант E02) |

Голоса реальных людей (***, ***) только для шуток на стриме: не выдавайте синтез за их настоящие слова.

Инструменты (Whisper, demucs, yt-dlp) стоят в `.venv` проекта (Python 3.11, torch cu124; cuBLAS/cuDNN
для faster-whisper берутся из `torch/lib`):

- `tools/meme/fetch-wiki-lines.py <api.php> <страница> <папка>` — реплики со страницы MediaWiki с текстом в `lines.json`
  (для CDN fandom нужен Referer, скрипт его ставит). Portal Wiki быстро отвечает 429, её проще читать из браузера.
- `tools/meme/extract-stalker.py <resources|localization> <регэксп> <папка>` — распаковка `.db` ЧН/ЗП (таблица файлов LZHUF,
  по исходникам OpenXRay). Голоса NPC лежат в `localization/base_sounds.db`, `characters_voice/human_0{1,2,3}/<группировка>/`.
- `tools/meme/transcribe-lines.py <аудио> --out <папка> [--demucs] [--lang ja] [--start/--end]` — нарезка длинной записи на фразы.
- `tools/meme/score-speaker.py <папка> <эталон...> [--iterate]` — сходство фраз с голосом (CAM++), поле `sim` в `lines.json`.
- `tools/meme/build-ref.py <папка> <голос> [--pick 1,5,9 | --min-sim 0.8] [--replace A=B]` — склейка образца в `voice-refs/meme/`.

Записи с YouTube: `.venv/Scripts/yt-dlp.exe -f bestaudio -x --audio-format m4a --download-sections "*0:00-25:00" <url>`.

**Сравнение вариантов** (`meme-pick.py`, только стандартная библиотека Python):

```bash
python tools/meme/meme-pick.py                      # http://localhost:8767 (конфигурация meme в .claude/launch.json)
python tools/meme/meme-pick.py --add *** V01 <аудио...> --text "…" --label "…" [--install <имя>]
python tools/meme/meme-pick.py --synth [голос ...]  # озвучить тестовые фразы, где синтеза ещё нет (нужен сервер)
python tools/meme/meme-pick.py --install            # поставить выбранное в voice-refs/meme
scripts/import-voices.sh voice-refs/meme --force
```

Варианты образцов лежат в `voice-clips/meme/<голос>/<id>.wav` и `.txt`, а их подписи, пример JeetBot и его текст — в
`voice-clips/meme/alts.json`. `S00` — образец, который стоит сейчас. У варианта может быть `install` — имя, под которым
он ставится: так `neco-arc` (японский оригинал) и `jeetbot-neco-arc` (клон JeetBot) сравниваются на одной карточке, и
можно взять оба. На странице для каждого голоса есть эталон JeetBot, сам образец и синтез трёх фраз с одним `seed`.
Первая фраза — демо-текст JeetBot для этого голоса, так что синтез сравнивается с их примером напрямую. Синтез лежит в
`voice-clips/meme/ab/`, выбор и заметки — в `voice-clips/meme/picks.json`. `--install` откладывает заменённые образцы
в `voice-refs/meme/replaced/<дата>/`.

**Голос жителя из его звуков.** Звуки жителя (idle, yes, no, haggle, 0,2–1 с) взяты из ассетов установленного
Minecraft (`%APPDATA%/.minecraft/assets`, по индексу `indexes/30.json`) и лежат в `voice-origs/minecraft-villager/`.
`tools/meme/villager-ref.py <выход.wav> [--len 10] [--gap 0.04-0.09] [--text hm|syl] [--seed N]` склеивает их в поток «речи»:
звуки идут в случайном порядке, у каждого срезано медленное нарастание (атака от −15 дБ, фейд 5 мс) и хвост,
высота немного плавает, паузы 40–90 мс, между «фразами» чуть длиннее. Рядом пишется текст-междометия («Хм хрм мм-хм.»).
Собранные образцы лежат в `voice-origs/minecraft-villager/refs/`.

CosyVoice на таком образце бормочет звуками жителя, но не умеет закончить фразу и тянет до предела длины
(14–26 с на короткую фразу). Поэтому у этих вариантов есть эффект `post`:
`effects/villager-fx.py --mode cut --text <фраза>`. Он обрезает синтез по длине, которую фраза заняла бы в речи
(12 символов в секунду), в ближайшем провале громкости. Синтез, который уложился в 1,8 расчётной длины, не трогается.
Слов Whisper в этом бормотании не находит.

Смешанный образец (звуки + речь) неустойчив. Когда звуки стоят перед речью, синтез то говорит, то бормочет, а когда
после — не говорит совсем. Отвергнуты на слух: эффект поверх обычного синтеза (`effects/villager-fx.py --mode
hum|half|mumble`, хмыки в паузах и замена слов звуками) и образец из звуков с паузами 0,25 с.
Голос с эффектом — это тот же образец плюс `post` в `voice-refs/meme/manifest.json`: при озвучке на стриме эффект
нужно применять к синтезу.
